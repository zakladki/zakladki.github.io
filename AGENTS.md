# Project Rules & Conventions

- **YouTube Music Playlists**: All YouTube playlist play buttons in the "Слухати Українську Музику" and "Слухати Закордонну Музику" cards use class `.yt-play-btn` with `data-playlist="<playlist_id>"`.
- **Shuffle Mode**: Every YouTube playlist playback must have shuffle (`setShuffle(true)`) enabled automatically by default.
- **Descriptions**: Description dashes should use standard hyphens `-` instead of long em-dashes `—`.
- **Automatic Changelog**: Every time a new resource, link, feature, page, or site modification is made, automatically log the update with the current date (format: YYYY-MM-DD) into `/CHANGELOG.md`.
